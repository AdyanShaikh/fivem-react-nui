# FiveM React NUI

Production-ready React + TypeScript + Vite starter for FiveM NUI resources.

## Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS 4
- FiveM Lua
- Typed NUI communication

## Goals

A reusable, framework-agnostic foundation for FiveM resources ranging from small scripts to complex interfaces such as banking, MDT, phone, inventory, HUD, and administration panels.
